## 📦 剩余需要手动执行的步骤

### 步骤 1: 下载 Index-TTS 节点（GitHub 网络限制）

由于当前主机无法直接连接 GitHub 进行 git clone，需要手动下载：

1. 浏览器访问: `https://github.com/chenpipi0807/ComfyUI-Index-TTS`
2. 点击绿色 **<> Code** 按钮 → **Download ZIP**
3. 将下载的 `ComfyUI-Index-TTS-main.zip` 解压
4. 将解压后的 `ComfyUI-Index-TTS-main` 文件夹**重命名**为 `ComfyUI-Index-TTS`
5. 将整个文件夹移动到: `D:\Program Files\AI\ComfyUI\custom_nodes\`

完成后目录结构应为:
```
D:\Program Files\AI\ComfyUI\custom_nodes\ComfyUI-Index-TTS\
    ├── nodes.py
    ├── requirements.txt
    ├── TTS2_download.py
    └── ...
```

---

### 步骤 2: 安装 Index-TTS 节点依赖

打开 PowerShell，执行:

```powershell
& "D:\Program Files\AI\ComfyUI\venv\Scripts\python.exe" -m pip install -r "D:\Program Files\AI\ComfyUI\custom_nodes\ComfyUI-Index-TTS\requirements.txt"
```

---

### 步骤 3: 安装 Windows 专用 pynini（文本正则化，重要！）

Index-TTS 在 Windows 上需要预编译的 pynini 轮子，否则数字/英文会读错。

1. 浏览器访问: `https://github.com/billwuhao/pynini-windows-wheels/releases`
2. 下载与你 Python 版本匹配的 whl 文件（Python 3.13 → `pynini-2.1.6.post1-cp313-cp313-win_amd64.whl`）
3. 在 PowerShell 中执行:

```powershell
# 安装 pynini（将路径替换为你实际下载的位置）
& "D:\Program Files\AI\ComfyUI\venv\Scripts\python.exe" -m pip install "D:\Program Files\AI\KnowledgeLib\pynini-2.1.6.post1-cp313-cp313-win_amd64.whl"

# 安装剩余依赖
& "D:\Program Files\AI\ComfyUI\venv\Scripts\python.exe" -m pip install importlib_resources
& "D:\Program Files\AI\ComfyUI\venv\Scripts\python.exe" -m pip install "WeTextProcessing>=1.0.4" --no-deps
```

### 步骤 4: 下载 Bernini 模型权重 (~40GB)

打开 PowerShell，执行:

```powershell

& "D:\Program Files\AI\ComfyUI\venv\Scripts\Activate.ps1"
```

### 步骤 6: 下载 FLUX.2 [dev] + SDXL（按你之前的计划）

**FLUX.2 [dev] FP8（官方 HuggingFace）**

```powershell
# 安装 huggingface_hub（如果还没装）
pip install -U huggingface_hub

# 下载三个文件
python -c "from huggingface_hub import snapshot_download; snapshot_download(repo_id='Comfy-Org/flux2-dev', local_dir=r'D:\Program Files\AI\ComfyUI\models\flux2-dev', allow_patterns=['*.safetensors'], resume_download=True)"

# 手动移动文件到正确位置:
# flux2_dev_fp8mixed.safetensors → models\diffusion_models\
# mistral_3_small_flux2_fp8.safetensors → models\text_encoders\
# flux2-vae.safetensors → models\vae\
```

或者直接在浏览器中从以下地址下载:
- https://huggingface.co/Comfy-Org/flux2-dev

**SDXL Checkpoint（推荐 1-2 个）**

| 模型 | 地址 |
|------|------|
| Juggernaut XL v9 | https://huggingface.co/RunDiffusion/Juggernaut-XL-v9 |
| Illustrious XL v1.0 | https://huggingface.co/OnomaAIResearch/Illustrious-XL-v1.0 |

放置位置: `D:\Program Files\AI\ComfyUI\models\checkpoints\`
