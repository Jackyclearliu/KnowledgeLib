# 🌸 视频下载爬虫

> 为 GPT-Sovits 训练数据集准备而设计的视频下载工具

## 📋 功能说明

本工具用于从视频网站下载视频文件，支持：

- **M3U8 流媒体**（`.m3u8`）：多线程分片下载 + ffmpeg 重新封装合并，输出 `.mp4`（时长元数据完整，剪辑软件可正常导入）
- **直链视频文件**（`.mp4` / `.flv` / `.mkv` / `.webm` / `.mov` / `.avi` / `.ts`）：单连接下载，支持断点续传
- **自动提取视频流地址**：只给播放页地址，自动从页面中找出视频流（video 标签 / 内嵌播放器配置）
- **交互式配置**：运行时逐项提示，直接回车使用默认值

根据视频流地址后缀自动选择处理方式；无后缀时通过 HEAD 请求探测 `Content-Type`。

## 🔧 文件结构

```
数据采集爬虫/
├── run_download.py          # 一键下载入口（交互式配置 + 格式分发）
├── m3u8_downloader.py       # M3U8 分片下载器（也可独立命令行使用）
├── direct_downloader.py     # 直链文件下载器（断点续传）
├── stream_finder.py         # 页面视频流地址自动提取
├── 下载视频.bat             # 一键启动批处理（仅作启动器，无中文，避免编码问题）
├── slice/                   # 下载中的临时数据（TS 片段 / .part 文件，支持断点续传）
├── result/                  # 下载完成后的完整视频文件
└── README.md                # 本说明文件
```

> 所有中文提示由 Python 输出，批处理文件保持纯 ASCII，不受 cmd 代码页影响。

## 🚀 使用方法

### 方法一：一键启动（推荐）

直接双击运行 **`下载视频.bat`**，按提示逐项配置（每项输入后回车确认，**直接回车使用默认值**）：

```
[1/4] 页面地址（用于防盗链 Referer 和自动提取视频流）
[2/4] 视频流地址（m3u8 或 mp4 等直链）—— 留空则自动从页面提取
[3/4] 输出文件名（无需扩展名，按流格式自动添加）
[4/4] 并发下载线程数（仅 M3U8 生效）
```

- 第 2 项留空时自动从页面提取视频流；找到多个候选时会列出编号供选择
- 自动提取失败（页面动态加载视频流）时，请用浏览器开发者工具（F12 → 网络）找到地址后手动填写
- 各项默认值写在 `run_download.py` 顶部的"默认配置区"，可直接修改

### 方法二：命令行自定义（仅 M3U8）

```bash
# 基础用法
python m3u8_downloader.py -u "M3U8_URL" -o "output.ts"

# 自定义参数（片段存 slice/，成品输出到 result/）
python m3u8_downloader.py \
  -u "https://cdn.xxx.com/xxx/index.m3u8" \
  -o "result/my_anime.ts" \
  --temp-dir "slice" \
  -r "https://www.yhdm28.com/" \
  -w 16
```

### 参数说明（m3u8_downloader.py）

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-u, --url` | M3U8 索引文件地址 | **必填** |
| `-o, --output` | 输出文件路径 | **必填** |
| `-r, --referer` | HTTP Referer 防盗链头 | `https://www.yhdm28.com/` |
| `-w, --workers` | 并发下载线程数 | `8` |
| `-t, --timeout` | 请求超时秒数 | `30` |
| `--temp-dir` | 临时文件目录 | 自动创建 |

## 📦 环境要求

- **Python 3.8+**（Windows 通常已预装）
- **ffmpeg**（用于合并 M3U8 片段并写入正确的时长元数据；未安装时回退为二进制拼接，可能出现时长显示异常）
- 无需额外 pip 依赖，纯标准库实现

## 🎯 工作流程

```
交互式配置（页面地址 / 视频流地址 / 文件名 / 线程数）
    ↓
视频流地址留空？ → 自动从页面提取候选流地址
    ↓
按流地址后缀分发（无后缀时 HEAD 探测）
    ├─ .m3u8 → 解析索引 → 多线程下载 TS 片段 → ffmpeg 重新封装合并为 .mp4
    └─ 直链  → 单连接下载 .part → 完成后改名输出
    ↓
清理临时数据 → 输出最终视频到 result/
```

下载中断后直接重新运行即可**断点续传**（M3U8 跳过已下载片段，直链从 .part 断点继续）。
